# Sistema de Vigilancia Epidemiológica de Dengue (ejemplo)

> Contenido ficticio, creado para probar el sistema multiagente.

## Propósito
Dar a epidemiólogos y analistas una vista semanal de los casos de dengue por
municipio, para priorizar acciones de control vectorial.

## Usuarios
- Epidemiólogos del equipo de vigilancia.
- Analistas de datos.
- Administrador de datos.

## Alcance de la versión 1.3
- Tablero con indicadores por municipio y semana epidemiológica.
- Exportación de datos agregados.
- Carga semanal de los archivos de notificación.
