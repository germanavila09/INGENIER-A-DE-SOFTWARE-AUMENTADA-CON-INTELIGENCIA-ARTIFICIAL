# Modelo de datos — PRJ001 (ejemplo ficticio)

Tabla `vigilancia.casos_dengue`:
- semana_epi (INT): semana epidemiológica.
- anio (INT)
- municipio_codigo (STRING): código DANE del municipio.
- edad (INT), sexo (STRING)
- clasificacion_caso (STRING): probable, confirmado por laboratorio o confirmado por nexo.
- documento_paciente (STRING): dato personal.

No existe todavía una tabla de población por municipio.
