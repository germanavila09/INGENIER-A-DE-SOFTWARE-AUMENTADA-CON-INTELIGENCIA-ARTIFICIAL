# Glosario del proyecto

_Documento de ejemplo con contenido ficticio, creado para probar el agente._

- **ADK**: Agent Development Kit de Google, marco para construir agentes.
- **Bucket**: contenedor de Cloud Storage donde se ingestan los documentos.
- **Ingesta**: proceso de cargar documentos al bucket para que el agente los use.
- **BM25**: algoritmo de ranking léxico usado por el índice de búsqueda.
